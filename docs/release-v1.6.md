## What's new in 1.6: colour tone and colour-blind help

Two new picture options, in the launcher's **Effects** tab and the pause menu's **Effects** tab:

- **Colour tone:** Original, **Warm** (a sunlit gold), **Cool** (a moonlit blue) or **Vivid** (richer colour everywhere).
- **Colour-blind help:** for **red-blind**, **green-blind** and **blue-blind** players. Colours that eye would see as the same are moved apart, so enemies, items, gems and magic stand out from what is around them. For example, the red health bar shifts toward pink, away from the greens.

Both change the console's own colour table, so they cost nothing to run and apply everywhere: at every internal resolution, with the CPU or the GPU effects, and in screenshots and previews. Lighting and the HDR look still go on top. The game itself plays exactly the same with them on.

Also in this release:

- **More previews:** HDR look, Colour tone and Colour-blind help now show a live before/after card on your paused frame. The previews of the other options now include the HDR grade you have on.
- The launcher's title art is always captured in the console's original colours, whatever tone you pick. Footsteps and texture-pack tile dumps also read the original colours.
- Leftover code from the old launcher design is gone, the game's own code builds without warnings, and the README now describes the redesigned launcher and pause menu.

**Updating:** run the new Setup over your install. It keeps your settings, saves and save states. Both new options start off, so the game looks as it did until you turn them on.
